Данный проект выполняется в рамках образовательной программы студентами 1 курса магистратуры ВШЭ по направлению ИИ.
___
## *Введение*
Приюту важно понимать, какие животные дольше ждут усыновления и где необходима дополнительная поддержка процесса пристройства. В проекте предлагается по сведениям, известным при поступлении животного, оценивать вероятность усыновления в течение 30 дней.
___
## *Цель проекта*
Разработать бинарную модель adopted_30d и сервис, который по карточке поступления питомца оценивает вероятность исхода Adoption в первые 30 дней.
___
## *План проекта*

### *1-й чекпоинт: Знакомство*

Обсуждение темы и плана работы. Создание репозитория.

### *2-й чекпоинт: EDA*
Иследование по предоставленным данным:
+ Подсчет доли всех пригодных для разметки эпизодов кошек и собак, закончившихся усыновлением за 30 дней.
+ Сравнение кошек и собак, возрастных групп,состояние при поступлении.
+ Исследование intake type, intake condition и сезонность поступлений.
+ Анализирование редких окрасов, intake subtype и reason_for_intake; объединие в редкие категории только по train-набору.
+ Проверка пропусков, повторные animal_id, правое цензурирование, некорректный dob, отрицательные/аномальные сроки и согласованность intake/outcome дат.

### *3-й и 4-й чекпоинты: ML-задачи*

+ DummyClassifier как baseline.
+ One-Hot Encoding + Logistic Regression как линейная модель.
+ CatBoostClassifier как нелинейная модель.
+ Использовать class weights или подбор порога, если adopted_30d несбалансирован.
+ Сравнить модели на одном фиксированном group test-наборе и провести анализ ошибок по группам животных.

### *5-й чекпоинт: Сервисная часть*
Создание небольшого сервиса:
+ Пользователь заполняет обезличенную карточку поступления питомца. Сервис возвращает вероятность усыновления в течение 30 дней. Дополнительно показывает калиброванную категорию вероятности: низкая / средняя / высокая. Интерпретация показывает статистические связи, но не даёт рекомендаций ограничивать помощь животным по возрасту, цвету, полу или состоянию.
+ Сохранить preprocessing и модель единым pipeline; добавить тесты диапазонов возраста и категорий.

### *6-й чекпоинт: DL-задачи*
+ Небольшой MLP на тех же табличных признаках.
+ Сравнить MLP с Logistic Regression и CatBoost на одном test-наборе.
+ Опционально использовать обучаемые embeddings частых категорий; изображения и тексты не требуются.
+ Зафиксировать и объяснить случай, если CatBoost превосходит нейросеть.

### *7-й чекпоинт: Возможные улучшения*
Представлен список возможных улучшений, некоторые из них будут представлены в проетке:
+ Подбор порога и калибровка вероятностей.
+ Более аккуратная обработка редких цветов, intake subtype и причин поступления.
+ SHAP или permutation importance.
+ Анализ качества по animal type, возрастным группам и периодам времени.
+ Проверка устойчивости при горизонтах 14, 30 и 60 дней как отдельный эксперимент; для каждого горизонта заново определить допустимое окно наблюдения относительно data_cutoff.
+ Метрики качества
  + PR-AUC.
  + F1-score.
  + ROC-AUC.
  + Precision и Recall для adopted_30d.

Важное ограничение
Это ретроспективные данные одного муниципального приюта. Правое цензурирование учитывается консервативным data_cutoff: слишком свежие поступления исключаются, а животные без исхода после полного 30-дневного окна относятся к классу 0.
___

## *Что хотим получить?* 
1. Бинарную модель adopted_30d на фиксированном открытом CSV.
2. Сервис для оценки обезличенной карточки поступления кошки или собаки.
3. Сравнение Logistic Regression, CatBoost и MLP.
4. Проанализированные факторы и группы, для которых модель ошибается чаще всего.
